3. Per què s'utilitzen aquestes Màquines Virtuals? (Justificació Tècnica)

En entorns professionals i en el currículum d'ASIX, no és admissible instal·lar tots els serveis en una o dues màquines. La distribució en 6 servidors s'argumenta estrictament per motius de seguretat, continuïtat de negoci i modelatge industrial:

  • Segregació de Xarxes (DMZ vs. LAN Interna): Un tallafocs perimetral mai ha de compartir host amb serveis d'aplicació ni bases de dades. A més, dmz-web és l'única màquina exposada a la WAN. Si pateix una vulnerabilitat a Nginx, l'atacant queda confinat a la DMZ (10.0.10.0/24); la política Default DROP d'OPNsense li impedeix accedir directament a les dades corporatives de la LAN.
  • Continuïtat de Negoci i Còpies de Seguretat (Model 3-2-1): Si les tasques de còpia s'executessin al mateix srv-serveis, una caiguda de maquinari, atac de ransomware o corrupció de disc destruiria la base de dades i els backups simultàniament (Single Point of Failure). srv-backup és una màquina aïllada amb un segon disc virtual dedicat muntat a /mnt/disc-extern-backup/.
  • Modelatge Real de Camp Rural (Edge Computing Autònom): La granja es troba a desenes de quilòmetres connectada per una xarxa 4G rural inestable. Els pollastres no poden dependre de la fibra òptica de la seu central per sobreviure: si la temperatura supera els 31 ºC, el gateway granja1-srv pren decisions autònomes i activa els ventiladors en menys de 2 segons en local.

4. Fitxes Tècniques Detallades: Què hi va a cada Màquina Virtual?

VM 1: fw-seu (Appliance de Seguretat Dedicat) OPNsense 24.x
vCPU / RAM2 vCPU | 2 GB RAM
Disc Dur20 GB VDI/VMDK
InterfíciesWAN, DMZ, LAN, VPN
IPs Assignades10.0.2.x, 10.0.10.1, 10.0.20.1
  • Enrutament i Tallafocs Perimetral: Política Default DROP a totes les potes de xarxa.
  • Llista blanca d'IPs de clients: Només autoritza trànsit HTTPS (:443) des de WAN cap a dmz-web.
  • Aïllament estricte DMZ → LAN: Només permet trànsit cap a srv-serveis:3306 (MariaDB) i :389 (LDAP).
  • Servidor WireGuard VPN (10.0.100.1): Reclou el trànsit de les granges permetent únicament el port MQTT 1883.
Justificació d'aïllament: Requeriment 4.4. Garanteix que la seguretat perimetral no es vegi compromesa si un servei intern falla.
VM 2: dmz-web (Servidor Web Frontal i Proxy Invers) Ubuntu Server 24.04
vCPU / RAM1 vCPU | 1 GB RAM
Disc Dur10 GB VDI/VMDK
XarxaInterna (dmz)
IP Assignada10.0.10.10 (GW: 10.0.10.1)
  • Nginx Reverse Proxy: Punt d'entrada segur que rep les peticions externes en HTTPS (:443).
  • Web Application Firewall (WAF): Capçaleres de seguretat HTTP, filtrat de peticions malicioses i rate-limiting.
  • Redirecció Segura cap a la LAN: Accés protegit cap al gestor phpLDAPadmin (http://10.0.20.10:8081).
Justificació d'aïllament: Principi de DMZ. Si el servidor web és vulnerat, l'atacant no té visibilitat ni accés directe als servidors de dades de la LAN.
VM 3: srv-serveis (Nucli de Serveis i Dades de la Seu) Ubuntu 24.04 + Docker
vCPU / RAM2 vCPU | 4 GB RAM
Disc Dur40 GB VDI/VMDK
XarxaInterna (lan-seu)
IP Assignada10.0.20.10 (GW: 10.0.20.1)
  • avigest_mariadb (MariaDB 10.11 - Port 3306): BD relacional primària, 11 taules 3FN, triggers de termòstat i vistes de tenant.
  • avigest_mariadb_replica (MariaDB 10.11 - Port 3307): Rèplica GTID en calent (Read-Only Standby).
  • avigest_mosquitto (Eclipse Mosquitto - Port 1883): Broker MQTT central que rep la telemetria via VPN.
  • avigest_mqtt_ingest (Python PyMySQL): Dimoni d'ingesta que guarda dades a lectures_sensors amb el rol avigest_iot.
  • avigest_openldap & phpldapadmin (Ports 389, 636, 8081): Directori LDAP centralitzat (dc=avigest,dc=cat) i consola web.
Justificació d'aïllament: Nucli de la informació corporativa. Mai s'exposa directament a la WAN ni a la DMZ; només s'hi accedeix per ports autoritzats.
VM 4: srv-backup (Servidor Dedicat de Còpies i PRD) Ubuntu Server 24.04
vCPU / RAM1 vCPU | 1 GB RAM
Disc Dur10 GB SO + 20 GB 2n disc
XarxaInterna (lan-seu)
IP Assignada10.0.20.20 (GW: 10.0.20.1)
  • Tasca Cron Nocturna (02:00 AM): Execució desatesa del pla de còpies de seguretat.
  • backup_avigest.sh: Buidatge remot amb mariadb-dump i slapcat, empaquetat .tar.gz i hash SHA-256.
  • Emmagatzematge a 2n Disc Virtual (/mnt/disc-extern-backup/): Simula la ubicació externa segons el model 3-2-1.
  • restaurar_avigest.sh: Script de restauració completa davant desastres (RTO < 30 minuts, RPO < 24 hores).
Justificació d'aïllament: Requeriment 4.5. Protegeix el repositori de recuperació davant d'una caiguda física, fallada o infecció de srv-serveis.
VM 5: granja1-srv (Gateway Industrial Edge de Camp) Ubuntu Server 24.04
vCPU / RAM1 vCPU | 1 GB RAM
Disc Dur10 GB VDI/VMDK
InterfíciesLAN Granja, NAT, WireGuard
IPs Assignades10.1.1.10 | VPN: 10.0.100.10
  • Broker MQTT Local: Recepció de telemetria dels microcontroladors de les naus i sitges.
  • Edge Computing d'Emergència: Si T > 31 ºC, activa immediatament els relés dels ventiladors en local (< 2 segons).
  • Autonomia Animal: Funciona de manera completament autònoma fins i tot si la connexió d'Internet o la VPN estan caigudes.
  • Cua Store-and-Forward: Reté telemetria en memòria local fins a 72 hores i la sincronitza quan torna la xarxa.
Justificació d'aïllament: Simula el hardware real instal·lat a la nau agrícola a desenes de quilòmetres de la seu central.
VM 6: granja1-sim (Simulador de Sensòrica i Silos) Ubuntu Server 24.04
vCPU / RAM1 vCPU | 1 GB RAM
Disc Dur10 GB VDI/VMDK
XarxaInterna (lan-granja1)
IP Assignada10.1.1.20 (GW: 10.1.1.10)
  • Simulador Python (simulador_iot.py): Emulació de dispositius físics de camp.
  • Bus Sèrie RS485 Modbus RTU: Emulació de sondes SHT30 (Temp/Humitat cada 30s) i sensor CO2 Senseair S8 (cada 60s).
  • Ràdio LoRaWAN 868 MHz: Emulació de pesatge de sitges de gra exterior cada 15 minuts.
  • Mode d'estrès: Permet generar pics de 34 ºC per comprovar com reaccionen el gateway, el tallafocs i els triggers de MariaDB.
Justificació d'aïllament: Requeriment 4.8. Simula el comportament dels microcontroladors ESP32 de camp dins del laboratori virtual.
VM 7: pc-client (Estació Client d'Auditoria Externa) Host Físic / VM Client
vCPU / RAM1 vCPU | 1 GB RAM
Disc Dur10 GB VDI/VMDK
XarxaNAT (internet-lab)
IP Assignada10.0.2.x (DHCP NAT)
  • Navegador Web: Proves d'accés per llista blanca cap a https://10.0.10.10 (DMZ).
  • Auditoria de Xarxa: Comprovació amb curl o nc que la xarxa LAN corporativa (10.0.20.0/24) és totalment inaccessible des de l'exterior.
Justificació d'aïllament: Demostra al professor que els clients accedeixen des d'Internet sense visibilitat de la infraestructura interna.
